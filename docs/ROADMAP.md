# MIO 后续演进路线图 (Roadmap)

本文档记录当前已完成基础架构建设、但有意延后实施的工程增强与功能演进事项，作为后续迭代的统一规划参考。

## 1. 发布工程与分发体验
- **代码签名与公证**：为 macOS 产物接入官方开发者签名与系统公证流程，为 Windows 产物接入平台可执行文件代码签名，消除首次运行时的系统安全拦截提示。
- **多平台 CI 发布矩阵**：在持续集成中自动构建并发布 `macos-arm64`、`macos-x86_64`、Linux 与 Windows 压缩包及配套 `SHA256SUMS.txt` 校验清单，确保与 `mio-core` 自动更新器的产物命名约定保持一致。
- **自动更新交互增强**：在现有远端 Release 资产版本检查、`SHA-256` 校验与自替换更新能力基础上，补充下载进度指示、断点重试与升级失败自动回滚保护。

## 2. 报文渲染与交互能力
- **真实浏览器引擎集成**：将 `Response -> Render` 视图从当前的静态 HTML/响应摘要预览演进为嵌入式真实浏览器视图，支持完整 DOM/CSS 排版布局、离线资源隔离与可控的脚本执行开关。

## 3. 安全扫描与带外检测
- **托管 / 远端 OAST 中继**：扩展 Collaborator 带外探测能力，支持对接可控的远端多协议中继服务端（HTTP/HTTPS/DNS 监听与关联回传），适配内外网隔离及异步延迟触发场景。
- **主 / 被动审计规则深化**：持续丰富内置漏洞指纹库与多步交互式主动扫描策略，进一步提升复杂参数注入、鉴权绕过与业务逻辑缺陷的检出率与低误报率。

## 4. 扩展生态（本地优先）
- **扩展索引与生命周期管理**：在坚持本地显式授权、离线目录及单文件归档加载优先原则的前提下，规划可选的自建静态扩展索引清单支持，以及扩展版本升级、兼容协议检查与完整性校验管理。

## 5. CLI / Agent 协同与代码整洁度
- **助手与 CLI 文案统一**：统一图形界面与命令行端围绕 `MioAT` / `MioAI` 及 IPC 控制能力的术语、帮助说明与示例文档，减少跨端概念分歧。
- **其余大型 UI 模块持续拆分**：继首轮拆分扩展管理、设置页、消息编辑器及 Match and Replace 等模块后，继续对剩余千行级 UI 模块按职责拆分为浅层组件（例如 `target/engagement.rs`、`tabs/render_pane/drawers.rs`、`audit_dashboard/workspace.rs`、`settings/connections.rs`、`tools_extra/logger/table.rs`），进一步降低编译单元体积并改善可维护性。
